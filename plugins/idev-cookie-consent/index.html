iDev Cookie Consent (PDPA / GDPR)

แบนเนอร์ขอความยินยอมคุกกี้ตาม PDPA และ GDPR: ยอมรับ ไม่ยอมรับ หรือเลือกประเภทเอง ถามทุกหน้าจนกว่าผู้ชมจะตอบ บันทึกหลักฐานความยินยอมพร้อมส่งออก CSV สคริปต์สถิติ/การตลาดรอจนได้รับความยินยอม และรองรับ Google Consent Mode v2

1ความสามารถ

  • 3 รูปแบบ: แถบเต็มความกว้าง · กล่องที่มุมจอ · กลางจอ (ต้องตอบก่อนใช้งาน)
  • แสดงทุกหน้าจนกว่าผู้ชมจะตอบ ก่อนหน้านั้นไม่จำอะไรไว้
  • ประเภท: จำเป็น (เปิดเสมอ) · สถิติ · สื่อจากภายนอก (แผนที่ วิดีโอ) · การตลาด
  • ปุ่ม ไม่ยอมรับ เห็นชัดเท่าปุ่มยอมรับ ตามที่หน่วยงานกำกับคาดหวัง
  • ปุ่มกลมเล็กที่มุมจอให้ เปลี่ยนใจ / ถอนความยินยอม ได้ทุกเมื่อ
  • บันทึกความยินยอม: รหัสสุ่ม ตัวเลือก เวลา หน้า เบราว์เซอร์ และค่าแฮชของ IP (ไม่เก็บ IP จริง) เก็บ 36 เดือน ส่งออก CSV
  • สคริปต์สถิติ/การตลาดที่วางในปลั๊กอิน ทำงานหลังผู้ชมยินยอมเท่านั้น · Google Consent Mode v2
  • ปลั๊กอิน iDev อื่นรอความยินยอม: แผนที่ (iDev Maps) และ Popup จะไม่บังแบนเนอร์

2เริ่มต้นใช้งาน

  1. ตั้งค่าทั่วไป

    iDevApp › คุกกี้และความเป็นส่วนตัว › ทั่วไป เลือกรูปแบบ ตำแหน่ง หน้านโยบายความเป็นส่วนตัว จำนวนวันที่จำคำตอบ และเปิดบันทึกความยินยอม

  2. แก้ข้อความ

    แท็บ ข้อความ หัวข้อและข้อความไทย/อังกฤษ ของแบนเนอร์

  3. ย้ายโค้ดติดตามมาที่นี่

    แท็บ ประเภทและสคริปต์ วางโค้ด Google Analytics / Facebook Pixel ในช่องของประเภทนั้น แล้ว ลบโค้ดเดิมออกจากธีม โค้ดจะทำงานเมื่อผู้ชมยินยอมแล้วเท่านั้น

  4. ปรับหน้าตา

    แท็บ หน้าตา สีพื้นหลัง ตัวอักษร ปุ่ม และรูปแบบปุ่มไม่ยอมรับ

เมื่อแก้นโยบายความเป็นส่วนตัว ให้เปลี่ยน เวอร์ชันนโยบาย (เช่น 1 → 2) ผู้ชมทุกคนจะถูกถามใหม่

3บันทึกความยินยอม

หากผู้ชมขอดูหรือลบบันทึกของตน รหัสความยินยอมอยู่ในคุกกี้ idev_consent (ส่วนระหว่างเครื่องหมาย |) ค้นหาด้วยรหัสนี้ในแท็บบันทึกความยินยอม

4iDev Cookie Consent Pro (1,900 บาท)

รุ่น Pro (zip เดียว มีตัวฟรีอยู่ในตัว) สำหรับองค์กรที่ต้องรับ คำขอใช้สิทธิ์ของเจ้าของข้อมูล และต้องมี หลักฐาน เมื่อถูกตรวจสอบ License ตลอดชีพ 1 เว็บไซต์ ช่วงทดลองใช้ได้ครบ แต่เอกสารที่พิมพ์จะมีคำว่า TRIAL

  • แบบฟอร์มคำขอใช้สิทธิ์ (บล็อก หรือ [idev_privacy_request]): ขอเข้าถึง/สำเนา ขอรับข้อมูล แก้ไข ลบ คัดค้าน ระงับ ถอนความยินยอม ใส่รหัสความยินยอมคุกกี้ให้อัตโนมัติ ส่งอีเมลยืนยันพร้อมเลขที่คำขอ
  • ทะเบียนคำขอ กำหนดตอบ 30 วันตาม PDPA เตือนเมื่อเกินกำหนด สถานะ บันทึกการตรวจตัวตน ตอบกลับทางอีเมล ประวัติทุกขั้นตอน ส่งออก CSV ชื่อและอีเมลถูก เข้ารหัส
  • ปุ่มลบบันทึกความยินยอมของผู้ขอ และเริ่มคำขอส่งออก/ลบข้อมูลด้วยเครื่องมือของ WordPress
  • ใบยืนยันการให้ความยินยอม ต่อรหัส: ประวัติการตอบ และ ข้อความแบนเนอร์/นโยบายที่ผู้ใช้เห็นจริง ณ เวลานั้น พิมพ์หรือบันทึก PDF
  • รายงานหลักฐาน ตามช่วงเวลา: ยอมรับ/ไม่ยอมรับ/เลือกเอง รายเดือน ประเภท เวอร์ชันนโยบาย ตรวจการตั้งค่า และคำขอค้าง
  • เวอร์ชันนโยบาย เก็บสำเนาอัตโนมัติทุกครั้งที่ข้อความหรือหน้านโยบายเปลี่ยน และเตือนเมื่อแก้นโยบายแต่ลืมเปลี่ยนเวอร์ชัน
  • สแกนคุกกี้และสคริปต์ เปิดหน้าเว็บแบบผู้เข้าชมครั้งแรก บอกว่า Google Analytics, Facebook Pixel, YouTube ฯลฯ ตัวไหนทำงานก่อนได้รับความยินยอม พร้อมวิธีแก้
  • กำหนดระยะเวลาเก็บบันทึกความยินยอมเองได้

Pro ต้องติดตั้งปลั๊กอินฟรี iDev Cookie Consent ไว้ก่อน เมนูอยู่ที่ iDevApp › ความเป็นส่วนตัว (Pro) · เครื่องมือนี้ช่วยเก็บหลักฐานและจัดการคำขอ ไม่ใช่คำแนะนำทางกฎหมาย

5Shortcode และสำหรับนักพัฒนา

Shortcodeผล
[idev_privacy_request]แบบฟอร์มคำขอใช้สิทธิ์ของเจ้าของข้อมูล (ต้องมี Pro)
[idev_cookie_settings]ลิงก์ "ตั้งค่าคุกกี้" เปิดแบนเนอร์อีกครั้ง (ใส่ใน footer หรือหน้านโยบาย)
[idev_cookie_settings]ตั้งค่าคุกกี้[/idev_cookie_settings]กำหนดข้อความลิงก์เอง

สคริปต์ที่ต้องรอความยินยอมแต่อยากวางเองในธีม ใช้ type="text/plain" และ data-idev-category="analytics" (หรือ external, marketing) ส่วน iframe ใช้ data-idev-src แทน src

<script type="text/plain" data-idev-category="analytics">
  /* โค้ด Google Analytics */
</script>

<iframe data-idev-src="https://www.youtube.com/embed/..." data-idev-category="external"></iframe>

<script>
  // JavaScript: ตรวจหรือรอความยินยอม
  if (window.idevConsent && idevConsent.allowed('external')) { /* ... */ }
  document.addEventListener('idev:consent', e => { /* ผู้ชมเพิ่งตอบ */ });
</script>

PHP: idev_consent_allowed('analytics')
