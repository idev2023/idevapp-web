    Plugins › Add New › Upload Plugin เลือกไฟล์ zip แล้วกด Install Now

  3. กด Activate

    รุ่น Pro และชุด I-Clinic / I-Drug ติดตั้ง ไฟล์เดียว (มีตัวฟรีอยู่ในตัว ถ้ามีตัวฟรีอยู่จะถูกปิดให้เอง ข้อมูลเดิมอยู่ครบ)

  4. อัปเดตอัตโนมัติ

    เมื่อมีรุ่นใหม่ WordPress จะอัปเดตให้เอง (ดูที่ Dashboard › Updates หรือการ์ด อัปเดต ใน iDevApp ปิดอัตโนมัติได้)

  5. ตั้งค่าที่เมนู iDevApp

    ปลั๊กอิน iDev ทุกตัวรวมอยู่ใต้เมนู iDevApp ในหลังบ้าน แต่ละตัวมีปุ่ม เปิด และ คู่มือ ที่ลิงก์มาหน้านี้
