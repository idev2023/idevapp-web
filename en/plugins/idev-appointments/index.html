iDev Appointments

Online appointments for doctors and clinics. Each doctor has their own booking link, with time slots and a limit per slot, automatic or staff confirmation, confirmation and reminder emails, self-service cancelling and rescheduling for patients, and a schedule page for each doctor.

  • WordPress 6.2+
  • PHP 7.4+
  • Language Thai / English
  • Requires iDev Clinic Schedule

1Features

Patients book in 4 steps: choose a doctor or clinic → choose a day and time → confirm who they are and accept the PDPA notice → get a booking number and a link to manage it

  • A booking link for each doctor / clinic e.g. /booking/dr-somchai/ share it on LINE or print it as a QR code
  • Time slots built from the clinic hours in iDev Clinic Schedule; set the slot length and bookings per slot for everyone or per doctor
  • Clinic closing days (iDev Thai Holidays) and doctors’ leave are skipped automatically
  • Patients without an HN register first they are taken to new patient registration and then back to booking
  • The PDPA / GDPR notice must be accepted before every booking and the consent version is stored with each booking
  • Automatic confirmation, or confirmation by the doctor / staff for everyone or per doctor
  • 6 emails: request received, confirmed, reminder before the day, reminder on the day, cancelled, rescheduled; the text can be edited in Thai and English
  • Patients cancel or reschedule themselves from the link in the email, with a deadline and a limit on reschedules · add to the phone calendar (.ics)
  • Doctor page doctors see their own appointments by day / week, confirm, reschedule, cancel and record arrivals and no-shows
  • Patient details in appointments are encrypted in the database

One file to install: the zip of iDev Appointments Pro already includes the free version. If the free version is installed, Pro switches it off for you and your data stays. The menu is at Appointments › Reports and Pro Included in I-Clinic / I-Drug, and iDev Appointments licences issued before version 1.2 work with Pro.

The HOSxP connector is an optional tool Connecting to and writing to the HOSxP database requires permission from BMS (the developer of HOSxP) and the hospital. The hospital decides whether to use it, sets the tables / columns, tests in dry-run mode and checks the data in HOSxP itself. This is outside iDevApp’s responsibility and must be accepted in the HOSxP tab before it can be switched on.

SMS is charged by the hospital’s own SMS provider · LINE uses the Messaging API of your LINE OA; patients add it as a friend and type their booking number to get alerts

3Getting started

Install and activate iDev Clinic Schedule first, because the doctors and their clinic hours come from that plugin

  1. Create the booking page

    Pages → Add New, name it e.g. "Online appointments" (suggested slug booking) and add the block Book an appointment from the iDevApp category, or type [idev_booking]

  2. Create the doctor page

    Create another page, e.g. "For doctors", with the block Doctor page or [idev_doctor_portal] Doctors open this page and sign in with their own WordPress account

  3. Set up booking

    Go to Appointments › Settings tab Booking Choose the booking page, the doctor page and the new patient registration page, then set the options in the table below

  4. Open booking for each doctor

    Open the doctor’s edit screen in Doctors and clinics the Online booking box on the right sets on / off, minutes per slot, patients per slot, confirmation, leave days and a note to patients. The doctor’s booking link is at the bottom of the box.

  5. Create accounts for doctors

    Users › Add New choose the role Doctor (appointments) then go back to the doctor’s edit screen and choose this account in Doctor account Staff who manage every doctor’s appointments use the role Appointment staff

  6. Set up emails and reminders

    tab Emails and reminders Enter the staff emails to notify, choose how many days before the appointment to remind and at what time, and edit the subject / text of each email

Reminder emails are sent by WP-Cron every hour. Set up a real cron job on the server and install an SMTP plugin so emails are delivered reliably (see "Troubleshooting").

5Page for doctors and staff

Doctors see only their own appointments; appointment staff and administrators see every doctor. The same page is in the admin under Appointments too (with the number waiting for confirmation)

  • Views day / week / waiting for confirmation search by name, HN or phone
  • Click an appointment to confirm · reschedule · cancel · arrived · no-show with a reason sent to the patient and an internal note
  • Confirm all in this list confirms several at once · Print the day’s appointment list
  • Add appointment for patients who call (staff can pick full slots)
  • Appointments with an unchecked HN or from online registration are labelled

7Troubleshooting

What do I need to do after updating from 1.1?

From 1.2 every doctor / clinic can be booked for free. If you bought a licence, install iDev Appointments Pro and your existing licence switches on LINE / SMS, the waiting list, branches, reports and the HOSxP connector

SMS / LINE messages aren’t sent

Look at the Latest messages table in the LINE / SMS tab, which shows the provider’s response, e.g. a wrong key, no credit, or the patient hasn’t linked LINE yet. Use Send a test SMS to check

Activating shows "requires 1 plugin … idev-clinic-schedule"

Install and activate iDev Clinic Schedule first, then iDev Appointments (from 1.0.1 activation isn’t blocked; a warning bar is shown instead)

The calendar has no free days

  • The doctor has no clinic hours in iDev Clinic Schedule,
  • the Online booking for the doctor is off,
  • Book at most ahead is too short, or every slot is full

The /booking/doctor-name/ link shows 404

Go to Settings › Permalinks and click Save once so WordPress rebuilds its links. If the doctor’s slug is in Thai, the English name is used for the link.

Emails aren’t sent / reminders are late

Install an SMTP plugin and send a test, and set up a real cron job on the server instead of WP-Cron:

*/15 * * * * curl -s https://example.com/wp-cron.php > /dev/null
