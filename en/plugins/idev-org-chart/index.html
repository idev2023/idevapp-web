1Features

  • 3 styles: People (cards with photos) · departments (coloured boxes) · compact
  • A tree editor: add below, move up / down, set the photo and colour of each box
  • Assistants / secretaries are shown beside the chain of command
  • Set how many levels are open; deeper levels open with + · expand all / collapse all
  • Link each person to a profile page · Thai / English names and positions

2Getting started

  1. Create a chart

    Org chart › Add chart Name it, e.g. "Executive board", then click Add top person / department

  2. Add people below

    Click Add below on any item, enter the name, position, photo and box colour, and tick Assistants / secretaries to show them at the side

  3. Set the display

    The Display box on the right: style, main colour, open levels, mobile style and Wider than the text column for large charts

  4. Put it on a page

    Copy the shortcode from the preview box, e.g. [idev_orgchart id="20"] or use the block Org chart and choose the chart

3Blocks and shortcodes

ShortcodeResult
[idev_orgchart id="20"]Shows chart ID 20
