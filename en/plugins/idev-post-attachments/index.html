iDev Post Attachments

Attach PDF, Word, Excel and other files to news and pages, drag to reorder, give them Thai / English names, and show the file type, size and download count (bots not counted).

  • Version 1.0.0
  • WordPress 6.2+
  • PHP 7.4+
  • Language Thai / English

1Features

  • Drag to reorder; Thai / English display names (empty = file name)
  • Styles: list or cards
  • After the content, before it, or wherever you place the block
  • Download counts bots not counted · opens in a new tab

2Getting started

  1. Attach files

    Open a news item or page; in the Attachments box under the editor click Attach files choose from the Media Library (several at once) and set the display names

  2. Settings

    iDevApp › Attachments Which content types, position, style, colours, file sizes and download counting

3Blocks and shortcodes

ShortcodeResult
[idev_attachments]This item’s files (block Attachments)
[idev_attachments post="25" style="cards" title="Documents"]Another post’s files, as cards, with your own title

Themes that place the list themselves declare add_theme_support('idev-post-attachments') · PHP: idev_attachments_render($post_id)
