Request a licence

Connecting to the HOSxP database requires permission from BMS (the developer of HOSxP). Customers contact BMS themselves; licence prices do not include this permission · a licence is for 1 website (domain); contact iDevApp to move it to another domain

How to buy and enter a licence

  1. Open the Licence page on your site

    Admin iDevApp › License shows your site’s domain e.g. hospital.example

  2. Email us for a licence

    Click Request a licence by email on that page (the plugin name and domain are filled in for you) or write to idevapp2023@gmail.com · call 095-638-0007 · Add on LINE

  3. Pay

    iDevApp sends you the bank transfer details and a receipt

  4. Paste the licence key

    You receive a key starting with IDEV1. Paste it in iDevApp › License and click Activate licence It works straight away, no internet connection needed

Installing a plugin (the same for all of them)

  1. Download the plugin file (.zip)

    You get the zip from iDevApp; don’t unzip it

  2. Upload it to WordPress

    Plugins › Add New › Upload Plugin choose the zip and click Install Now

  3. Click Activate

    Pro versions and the I-Clinic / I-Drug packages install as one file (the free version is included; if it is already installed it is switched off for you and your data stays)

  4. Automatic updates

    WordPress updates the plugins when a new version comes out (see Dashboard › Updates or the Updates card in iDevApp where automatic updates can be turned off)

  5. Settings in the iDevApp menu

    All iDev plugins are under the iDevApp menu in the admin. Each one has Open and Guide buttons; Guide links to these pages

Requires WordPress 6.2+ and PHP 7.4+ · each iDev plugin works on its own except iDev Appointments which needs iDev Clinic Schedule · always back up the database and the wp-content folder before updating a live site
