iDev Popup Notice

Popups for important notices with a picture and button, start and end times, one at a time, hidden for a set number of hours after the visitor closes them, waiting for the cookie banner, and never shown on booking or registration forms.

  • Version 1.0.0
  • WordPress 6.2+
  • PHP 7.4+
  • Language Thai / English

1Features

  • Title, text, button and link in Thai / English, with a featured image
  • Set start / end times in the site’s timezone
  • Several popups show one at a time with a "Next notice" button, in order
  • Closed popups stay hidden for N hours; editing the text shows them again
  • Waits for the cookie banner to be answered, and is not shown on booking, registration and doctor pages
  • Show on every page or only the home page, with an optional delay

2Getting started

  1. Create a popup

    Popup notices › Add popup Enter the title, text, button and dates, and set the featured image as the popup picture

  2. Display settings

    iDevApp › Popup settings Where to show (every page / home page only), hours hidden after closing, delay and colours

To pause, switch to Draft · order: Attributes → Order (lower first)

3For developers

Hide popups on chosen pages with the filter idev_popup_show

add_filter('idev_popup_show', function ($show) {
    return is_page('checkout') ? false : $show;
});
