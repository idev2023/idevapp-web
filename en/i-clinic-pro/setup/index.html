Before you start

Have these 6 things ready

Use the computer that stays on during opening hours. It becomes the clinic's "server"; other computers and tablets use the system through it.

Windows 10 / 11, 64-bit4 GB RAM or more, at least 2 GB free on drive C:
An administrator accountWindows asks for permission when the setup starts; you must be able to click Yes
Internet (first time only)The installer downloads about 70 MB. After that the system works on the clinic network without internet.
Clinic detailsClinic name, address, phone and PromptPay number (if any) for the receipts. You can change them later.
Administrator e-mailUsed to reset the password and to receive system notices
Close programs using port 80 (if any)For example IIS, XAMPP or an old Skype. If you can't close them, the installer uses port 8080 instead.
Tip: give this computer a fixed IP addresson the router (DHCP reservation), so tablets and other computers always find it at the same address. If that's not convenient, use the computer name instead of the IP.

Install steps

Install step by step

Follow the steps in order. Tick "I've done this step" as you go; if you stop halfway, this page remembers your ticks in the browser you're reading it on.   6. Wait for the setup to finish

    The installer does everything by itself; you don't need to click anything. A green OK line means that step is done.

    • Installs the Visual C++ Runtime, Apache, PHP 8.3 and WordPress in Thai
    • Installs I-Clinic Pro and its theme, and creates the booking, registration, doctor schedule, doctor and job status pages
    • Sets it up as a Windows service that starts every time the computer starts
    • Opens the Firewall so other computers in the clinic can connect
    • Sets up the automatic jobs and a nightly backup at 02:30
    If you see a red XX linethe installer stops and shows the name of its log file. See Troubleshooting then run Setup.cmd again.

  7. Keep the password safe

    When the setup is done, Notepad opens the file C:\iClinic\ข้อมูลเข้าระบบ.txt by itself (the name means "sign-in details"). It contains:

    • The web addresses for this computer and the other clinic computers
    • The username and admin password

    Write the password down somewhere safe (e.g. a password manager). After that you may delete the file. Only administrators of this computer can open it.

After installing

Tools in C:\iClinic

Double-click to use. Each one asks for administrator permission first.

Backup-now.cmdBack up now (the system already backs up every night at 02:30 and keeps 30 days in the backup folder)
Restore.cmdRestore from a backup file. The data before restoring is kept so you can go back.
Open-to-internet.cmdOptional: let patients book or register from outside the clinic through a Cloudflare Tunnel (https). Needs a Cloudflare account.
Uninstall.cmdUninstall. Patient data is not deleted unless you type the confirmation.
FolderWhat's in it
C:\iClinic\dataDatabase and encryption keys. All patient data is here. Never delete it.
C:\iClinic\backupDaily backups. Copy them off the computer (USB / NAS) regularly, or change the location in iclinic.json setting "BackupDir"
C:\iClinic\wwwThe program (WordPress)
C:\iClinic\logsLogs. Send these to support if something goes wrong.
Always keep a backup off the computerIf the hard disk fails or the computer is lost, backups on the same computer are lost too.
Troubleshooting

Common problems

Setup.cmd closes straight away

Check that you extracted the zip (step 3) and clicked Yes when Windows asked. If it still fails, right-click Setup.cmd › Run as administrator

It says "needs 64-bit Windows" or "needs Windows 10 or 11"

This computer can't be used. Check at Settings › System › About: it must be a 64-bit operating system, Windows 10 or later.

Apache download fails

Sometimes the source site renames its files. Download it yourself from apachelounge.com/download choose the file httpd-2.4.x-win64-VS17.zip put it in the packages folder of the installer and run Setup.cmd again.

Any other program that fails to download can be added the same way.

It says port 80 / 8080 is in use

Close that program (usually IIS, XAMPP or WAMP) and run Setup.cmd again. If you can't close it, choose a port yourself: open Command Prompt as Administrator in the installer folder and type Setup.cmd -Port 8081

It says "system already installed"

I-Clinic Pro is already on this computer. Update it from the admin (Dashboard › Updates). To really reinstall, first run C:\iClinic\Uninstall.cmd (existing data is not deleted).

Other computers or tablets can't open the site

1) Set the server computer's network to Private 2) Try the IP address instead of the computer name 3) Check the tablet is on the same Wi-Fi, not a guest Wi-Fi 4) If your antivirus has its own firewall, allow port 80

The site doesn't come up after a restart

Press Win+R and type services.msc find "I-Clinic Pro (เว็บเซิร์ฟเวอร์)" and click Start. If it still fails, send the file C:\iClinic\logs\apache-error.log to support.

Forgot the admin password

Click "Lost your password?" on the sign-in page (e-mail must be set up), or open C:\iClinic\ข้อมูลเข้าระบบ.txt if you haven't deleted it, or contact support.

The phone camera won't scan ID cards

Browsers only allow the camera on https pages or localhost, so it doesn't work on a plain clinic network. Type the details or upload a photo instead, or open the site through Open-to-internet.cmd, which gives you https.

Can I install another computer without internet?

Yes. After the first install, the installer's packages folder holds every program it downloaded. Copy the whole I-Clinic-Pro-Setup folder to the other computer and run Setup.cmd.

Moving the system to a new computer

Install on the new computer with this installer, then use Restore.cmd with a backup from the old one. If the computer name changes, ask iDevApp for a new licence key.
