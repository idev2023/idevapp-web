# idevapp-web

เว็บไซต์ของ iDevApp (idevapp.me): แนะนำผลิตภัณฑ์ I-Office, I-Queue, I-Download และ I-Appointment

- เว็บนิ่ง (HTML/CSS/JS) ไม่ต้อง build
- `index.html` คือหน้าหลัก รูปทั้งหมดอยู่ใน `img/`
- Deploy ด้วย Cloudflare Pages: Framework preset = None, Build command = (ว่าง), Build output directory = `/`
