ติดตั้ง I-Clinic Pro บนคอมพิวเตอร์ Windows

สำหรับคอมพิวเตอร์ในคลินิกที่ยังไม่มีอะไรเลย ดับเบิลคลิกครั้งเดียว ตอบคำถาม 6 ข้อ แล้วรอประมาณ 5–10 นาที ได้ระบบคลินิกพร้อมใช้ ทุกเครื่องในคลินิกเปิดผ่านเบราว์เซอร์ได้ ไม่ต้องรู้เรื่องเซิร์ฟเวอร์

Windows 10 / 11 (64 บิต)ไม่ต้องลง MySQLใช้ในวงแลนได้โดยไม่ต้องมีเว็บโฮสติ้งสำรองข้อมูลทุกคืน

    ถ้าดาวน์โหลดจากเครื่องอื่น คัดลอกไฟล์ใส่แฟลชไดรฟ์มาก็ได้

  2. ปลดล็อกไฟล์ (Unblock)

    Windows จะติดป้าย "ไฟล์จากอินเทอร์เน็ต" ไว้ ถ้าไม่ปลดก่อน จะมีหน้าต่างเตือนหลายครั้งระหว่างติดตั้ง

    1. คลิกขวาที่ไฟล์ zip › Properties (คุณสมบัติ)
    2. แท็บ General ด้านล่าง ติ๊กช่อง Unblock (ยกเลิกการบล็อก)
    3. กด OK
    ถ้าไม่เห็นช่อง Unblock แปลว่าไฟล์ไม่ได้ถูกบล็อก ข้ามไปขั้นต่อไปได้เลย

ขึ้นว่า "ต้องใช้ Windows 64 บิต" หรือ "ต้องใช้ Windows 10 หรือ 11"

เครื่องนี้ใช้ไม่ได้ ดูรุ่นที่ Settings › System › About ต้องเป็น 64-bit operating system และ Windows 10 ขึ้นไป

ดาวน์โหลด Apache ไม่สำเร็จ

บางครั้งเว็บต้นทางเปลี่ยนชื่อไฟล์ ดาวน์โหลดเองจาก apachelounge.com/download เลือกไฟล์ httpd-2.4.x-win64-VS17.zip วางในโฟลเดอร์ packages ของตัวติดตั้ง แล้วเปิด Setup.cmd ใหม่

โปรแกรมอื่นที่ดาวน์โหลดไม่สำเร็จ ใช้วิธีเดียวกันได้

ขึ้นว่าพอร์ต 80 / 8080 มีโปรแกรมอื่นใช้อยู่

ปิดโปรแกรมนั้น (มักเป็น IIS, XAMPP หรือ WAMP) แล้วเปิด Setup.cmd ใหม่ ถ้าปิดไม่ได้ ให้ระบุพอร์ตเอง: เปิด Command Prompt แบบ Administrator ในโฟลเดอร์ตัวติดตั้ง แล้วพิมพ์ Setup.cmd -Port 8081

ขึ้นว่า "พบระบบที่ติดตั้งไว้แล้ว"

เครื่องนี้มี I-Clinic Pro อยู่แล้ว อัปเดตได้จากหลังบ้าน (แดชบอร์ด › อัปเดต) ถ้าต้องการติดตั้งใหม่จริง ๆ เปิด C:\iClinic\Uninstall.cmd ก่อน (ข้อมูลเดิมไม่ถูกลบ)

เครื่องอื่นหรือแท็บเล็ตเปิดเว็บไม่ได้

1) ตั้งเครือข่ายของเครื่องเซิร์ฟเวอร์เป็น Private 2) ลองเปิดด้วย IP แทนชื่อเครื่อง 3) ตรวจว่าแท็บเล็ตต่อ Wi-Fi วงเดียวกัน ไม่ใช่ Wi-Fi แขก 4) ถ้ามีโปรแกรมแอนตี้ไวรัสที่มี Firewall ของตัวเอง ต้องอนุญาตพอร์ต 80

เปิดเครื่องใหม่แล้วเว็บไม่ขึ้น

กดปุ่ม Win+R แล้วพิมพ์ services.msc หา "I-Clinic Pro (เว็บเซิร์ฟเวอร์)" แล้วกด Start ถ้ายังไม่ได้ ส่งไฟล์ C:\iClinic\logs\apache-error.log ให้ทีมงาน

ลืมรหัสผ่านผู้ดูแล

กด "ลืมรหัสผ่าน?" ที่หน้าเข้าสู่ระบบ (ต้องตั้งค่าส่งอีเมลไว้แล้ว) หรือเปิดไฟล์ C:\iClinic\ข้อมูลเข้าระบบ.txt ถ้ายังไม่ได้ลบ หรือติดต่อทีมงาน

กล้องมือถือสแกนบัตรประชาชนไม่ทำงาน

เบราว์เซอร์อนุญาตใช้กล้องเฉพาะหน้าเว็บ https หรือ localhost ในวงแลนธรรมดาจึงใช้กล้องไม่ได้ ให้กรอกเองหรืออัปโหลดรูปแทน หรือเปิดผ่าน Open-to-internet.cmd ซึ่งได้ https

ติดตั้งเครื่องอื่นโดยไม่มีอินเทอร์เน็ตได้ไหม

ได้ หลังติดตั้งเครื่องแรก โฟลเดอร์ packages ของตัวติดตั้งจะมีโปรแกรมที่ดาวน์โหลดไว้ครบ คัดลอกโฟลเดอร์ I-Clinic-Pro-Setup ทั้งโฟลเดอร์ไปเครื่องอื่นแล้วเปิด Setup.cmd

ย้ายระบบไปเครื่องใหม่

ติดตั้งบนเครื่องใหม่ด้วยตัวติดตั้งนี้ แล้วใช้ Restore.cmd กู้จากไฟล์สำรองของเครื่องเดิม ถ้าชื่อเครื่องเปลี่ยน ต้องขอ license key ใหม่จาก iDevApp
